# Select inline

O `SelectInline` está **obsoleto**: ele continua funcionando, mas telas novas devem usar um `Combobox` com `inline`, que o substitui.

O select inline é um botão pequeno que mostra a opção escolhida e abre uma lista com busca, usado dentro de uma frase ou de uma barra de ferramentas, como "Mostrando pedidos dos Últimos 30 dias".

## Boas práticas

- Use-o onde um campo completo ocuparia espaço demais, como no cabeçalho de uma tabela ou de um gráfico.
- Mantenha curto o texto do botão e faça dele a opção escolhida, para que a frase continue fazendo sentido.

## Migrando para o Combobox

Troque o `SelectInline` pelo `Combobox` com `inline`. As props principais mantêm os nomes: `items`, `value`, `onChange`, `itemToString` e `defaultButtonText`. O placeholder da caixa de busca passa para `searchBoxPlaceholder`.

```jsx
// Antes
<SelectInline items={periods} value={period} onChange={setPeriod} itemToString={toLabel} defaultButtonText='Período' />

// Depois
<Combobox inline items={periods} value={period} onChange={setPeriod} itemToString={toLabel} defaultButtonText='Período' />
```

## Acessibilidade

O botão do `Combobox` com `inline` informa aos leitores de tela se a lista está aberta, e abri-lo leva o foco para a caixa de busca, que é o combobox da lista. As setas percorrem as opções, o Enter escolhe uma e o Escape fecha a lista; nos dois casos, o foco volta para o botão. Sem a caixa de busca, o próprio botão é o combobox.
