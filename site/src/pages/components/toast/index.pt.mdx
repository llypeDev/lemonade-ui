# Toast

Utilize _toasts_ para mostrar informações que requerem mínima interação do usuário. As mensagens desaparecem após 5 segundos ou podem ser fechadas manualmente e são apresentadas nos cantos inferiores da tela. As mensagens não podem atrapalhar o fluxo de trabalho do usuário. São comumente utilizadas para alertar sobre _status_ de tarefas.

## Boas práticas

- Mensagens devem limitar seu corpo de texto em no máximo duas linhas.
- Devem desaparecer automaticamente após 5 segundos, e devem ter um ícone de fechar. Se entrar no _status_ de _hover_, a _toast_ deve ser mantida aberta.
- Podem ser incluídos links que redirecionam o usuário para próximos passos.
- Utilize ícones para transmitir clareza adicional. Os ícones informativos devem ser posicionados à esquerda do título.

## Uso

Envolva a aplicação uma vez com o `ToastProvider` e chame `useToast().show()` em qualquer lugar dentro dele. Os _toasts_ aparecem no canto inferior esquerdo da tela, fecham após 5 segundos (`duration`; use `0` para mantê-los abertos) e continuam abertos enquanto estiverem com o mouse em cima ou com foco. Leitores de tela anunciam as mensagens por uma região _live_ educada (`aria-live="polite"`).

O `type` (`info`, `success`, `warning` ou `danger`) define o ícone informativo. Use `action` para um link que permita ao usuário responder à mensagem.

## Migrando do ActionableToast

`ActionableToast`, `ActionableToastList` e `useToastMessages` estão obsoletos e serão removidos numa próxima versão _major_. A correspondência com a nova API é:

| Antes                                                 | Depois                                                                               |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `useToastMessages()` + `<ActionableToastList data />` | `<ToastProvider>` em volta da aplicação + `useToast()`                               |
| `showToast(options)`                                  | `toast.show(options)`                                                                |
| `secondsVisible` (segundos)                           | `duration` (milissegundos)                                                           |
| `action` + `buttonLabel`                              | `action`: qualquer elemento, como um `Link` ou um `Button` com seu próprio `onClick` |
| `newToast` (bolinha vermelha)                         | sem equivalente: use `type` para definir o ícone e a cor                             |
