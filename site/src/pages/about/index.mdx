# About us

Lemonade is an open source design system focused on accessibility, consistency and simplicity. It provides a set
of React components, design guidelines and resources for building accessible digital products, always keeping the
people who use them in mind.

## Our principles

- **Accessibility first:** components are built following the WCAG specifications at AA level, with semantically
  correct markup and appropriate ARIA attributes.
- **Consistency:** shared color, typography, grid and iconography guidelines keep interfaces coherent across
  products.
- **Open source:** the code is public and available as an [npm package](https://www.npmjs.com/package/@lemonade/ui).
- **Customization:** themes can be customized and switched between light and dark modes.

## Our development process

We carried out an extensive search for references to develop our components and were inspired by various design
systems, mainly the <a href="https://www.carbondesignsystem.com/">Carbon Design System</a> and
<a href="https://atlassian.design/">Atlassian Design</a>, as well as the
<a href="https://www.nngroup.com"> NN Group</a> usability recommendations.

During the development stage, we also discussed the components with developers and business analysts to cover as
many use cases as possible. **The components and results of this project were also tested with users to measure
and meet the usability criteria.**
